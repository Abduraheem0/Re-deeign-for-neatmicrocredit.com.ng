# N.E.A.T Microcredit – UI redesign: handoff notes

## Run it
```
cd html && python3 -m http.server 8080      # open http://localhost:8080
```
Plain static HTML/CSS/JS, so any static host works. The shared header, footer and page content are generated by `build.py`
(`pip install beautifulsoup4 lxml`, then `python3 build.py`). Edit once there and every page updates. The previous build is kept in `_original-version/`;
unlinked scratch pages and the old `style.css` were moved to `html/_archive/`.

## What changed
* New design system in `html/css/neat.css` (tokens at the top), tiny `html/js/neat.js` (no libraries), optimised WebP images in `html/images/opt/`.
* All 18 public pages redesigned; page weight dropped from ~90–360 KB to 17–32 KB HTML each.
* Header: top bar, sticky header, product mega-menu, accessible mobile drawer (closes on link/Esc/backdrop), site search, yellow "Get a Loan" CTA.
* Home: hero, trust strip, About, services bento, Why N.E.A.T, funding + calculator, milestones, testimonials, partners, CTA, new footer.
* FAQs / savings / philosophy use native `<details>` accordions (keyboard accessible, no JS).

## Tested (headless Chromium)
No horizontal overflow at 320, 360, 375, 390, 414, 430, 768, 1024, 1280, 1440 px on all 18 pages · no broken internal links/anchors or images ·
no JS errors · drawer, submenu, search, calculator, form validation, counters, Esc handling, reduced-motion checked.
Not possible here: real phones/Safari, Google Fonts and the Google Map (sandbox has no internet), screen-reader testing.
